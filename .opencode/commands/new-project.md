---
description: Create new OpenCode project from template
---

Create a new OpenCode project using the template and switch to it.

Usage: `/new-project <project-name>`

Steps:
1. Run in terminal: `/opt/new-opencode-project.sh <project-name>`
2. Wait for server restart (5-10 seconds)
3. Refresh https://opencode.aldervall.se
4. Run `/init` to generate AGENTS.md for the new project

Note: This will switch the server to the new project automatically.
