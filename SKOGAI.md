## What This Repo Is

`wooking-for-work` is an AI-assisted job-hunting automation framework for the Swedish/European IT job market, built on [opencode](https://opencode.ai). It connects three external systems via MCP servers and provides a 5-agent CrewAI pipeline for deep resume optimization.

## CrewAI Pipeline (`src/resume_optimizer/`)

Five agents run **sequentially** via `Process.sequential`:

| Step | Agent | Output file | Model |
|------|-------|-------------|-------|
| 1 | `job_analyzer` | `output/job_analysis.json` | `JobRequirements` |
| 2 | `resume_analyzer` | `output/resume_optimization.json` | `ResumeOptimization` |
| 3 | `company_researcher` | `output/company_research.json` | `CompanyResearch` |
| 4 | `resume_writer` | `output/patch_operations.json` | `ResumePatches` |
| 5 | `report_generator` | `output/final_report.md` | plain markdown |

### Running the pipeline

```bash
uv run --directory src/resume_optimizer python -m resume_optimizer.main \
  --job-listing /tmp/resume-optimizer/job_listing.json \
  --job-enrichment /tmp/resume-optimizer/job_enrichment.json \
  --resume /tmp/resume-optimizer/resume.json \
  --company-name "Company AB" \
  --company-data /tmp/resume-optimizer/company_data.json   # optional
```

All four input files are gathered by `@resume-optimizer` via MCP before launching the crew.

## Key Invariants

These rules are repeated in every agent prompt and every rules file:

- **Never auto-send** applications — every step saves locally for review first
- **Slug format** — CV: `[company]-[role]-$(date +%s)` | Cover letter: `pb-[company]-[role]-$(date +%s)`
- **Never mix languages** — Swedish stays Swedish, English stays English, never both in one resume
- **Fetch after duplicate** — always call `reactive_resume_get_resume` on the *new* resume ID before saving locally; saving the base resume breaks links
- **Secrets from .env only** — `opencode.json` uses `{env:VAR}` syntax; nothing hardcoded

## Monthly Obligation

Submit **aktivitetsrapport** to Unionen A-Kassa by the last day of each calendar month. Template: `cover-letters/mall-aktivitetsrapport.md`. Workflow: `@affine-docs` → collect all jobs from AFFiNE → format table → email body → log in AFFiNE Correspondence.
